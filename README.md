 # STM32-Based Control Unit
## Project Overview

This engineering project was developed at ENSEA (École Nationale Supérieure de l'Électronique et de ses Applications) as part of a team-based electronics project.

The objective was to design a control unit based on an STM32 microcontroller for a power converter, combining embedded electronics, a human-machine interface, and custom printed circuit boards (PCBs).

The system includes an STM32L476RG microcontroller, a TFT display, push buttons, a rotary encoder, and dedicated electronic boards.

## Hardware Design

### 1. Button Interface PCB

A custom PCB designed with KiCad for the control unit's push-button interface and user controls.

### 2. USB-C Communication PCB

A dedicated PCB designed with KiCad to support the control unit's USB-C interface and associated electronic connections.

## My Contributions
